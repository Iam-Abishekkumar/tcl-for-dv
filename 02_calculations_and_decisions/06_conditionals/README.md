# 06 · Conditionals: if, switch, ternary

`if {…} {…} elseif {…} {…} else {…}`: `} elseif {` and `} else {` stay on the same line as the closing brace.
Compare numbers with `==` `<`, text with `eq` `ne`. `switch` matches exactly; `default` (no s) catches the rest.
